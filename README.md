# Zalupa DayZ — лаунчер и сборка модов

Официальный склад **Minecraft-сервера Zalupa DayZ** (1.20.1, Forge).
Здесь живут две вещи:

- **Релизы лаунчера** — раздел **[Releases](../../releases)** справа → скачай последний `ZalupaDayZ-Setup-*.exe`
- **Сборка модов** — файл `manifest.json` и папка `mods/`. Лаунчер игроков сам скачивает и обновляет их.

---

## 🎮 Игроку: установка за 3 шага

1. Зайди в **[Releases](../../releases)** и скачай последний **`ZalupaDayZ-Setup-*.exe`**
2. Если Windows покажет синее окно SmartScreen — нажми **«Подробнее» → «Выполнить в любом случае»** (это нормально для лаунчеров без платной подписи)
3. Запусти лаунчер → введи **ник** → жми **«Играть»**

> Первый запуск скачивает Minecraft, Forge и моды (несколько минут). Дальше всё быстро.

**Кнопки лаунчера:**
- **Играть** — сам проверит сборку, докачает обновления и запустит игру
- **Обновить** — появляется, когда вышло обновление сборки или самого лаунчера

---

## 🛠 Админу сервера: как обновить моды

1. Открой лаунчер и нажми **Ctrl + Shift + A** → введи пароль админа
2. **«+ Добавить моды…»** → выбери `.jar` файлы (моды качай с CurseForge/Modrinth — версия **1.20.1 Forge**)
3. **«Опубликовать сборку»** — у всех игроков появится кнопка «Обновить»

Всё. Никакого сайта GitHub трогать не нужно — это хранилище работает само.

---

## ℹ️ Технические подробности

- `manifest.json` — версия сборки + контрольные суммы (sha256) каждого мода
- Лаунчер качает **только изменённые файлы** и проверяет их целостность
- Моды, которых нет в сборке, автоматически удаляются с компьютера игрока —
  читерские и посторонние моды не приживутся
